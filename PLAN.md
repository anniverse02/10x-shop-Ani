10X Shop - Project Plan

1. About the Project

For this assignment, I am going to build a small online shop called 10X Shop.

The application will allow users to browse products, open product pages, add items to their cart and place an order.

I will use React and TypeScript to build the application. My first priority is to complete all CORE requirements. If everything works as expected, I will continue with some of the FULL features.

2. Technologies

I will use the following technologies:

React 19

TypeScript

Vite

React Router

Tailwind CSS v4

DummyJSON API

Git and GitHub

Vercel or Netlify for deployment

3. What I Plan to Build

CORE Features

These are the main features I need to complete:

Login: A simple login page with local authentication.

Home page: A page where users can see the available products.

Product details: Users can open a product and see more information about it.

Shopping cart: Users can add products, remove them and change quantities.

Checkout: A form where users enter their information and place an order.

Order confirmation: A message displayed after a successful checkout.

I will also add loading, error and empty states where needed.

FULL Features

After finishing the main requirements, I would like to work on:

Product search and filtering.

Sorting and pagination.

Product reviews and ratings.

Related products.

Promo codes.

Order history.

User profile.

Light and dark themes.

5. Possible Problems

During development, I may face some problems. Here are a few things I want to be prepared for.

1. Problems with the API

Sometimes product data may not load because of network or API errors.

To handle this, I will add loading and error messages and make sure the application does not break when a request fails.

2. Problems with the shopping cart

It may be difficult to keep cart information updated across different pages.

I plan to use React Context to manage the cart state and keep product quantities and prices correct.

3. TypeScript errors

I may have problems with types, especially when working with API data.

I will define the necessary types and interfaces and check my code regularly.

4. Responsive design

Some parts of the application may not look good on smaller screens.

I will test the application on mobile, tablet and desktop sizes and fix layout problems when I find them.

6. How I Will Test the Project

I will test the application during development, not only at the end.

I plan to check:

If all pages open correctly.

If products load from the API.

If product details show the correct information.

If adding and removing products works.

If cart quantities and totals are correct.

If checkout validation works.

If the cart becomes empty after a successful order.

If the application works on smaller screens.

I will also run ESLint, TypeScript checks and a production build to find possible errors.

7. Definition of Done

I will consider the CORE part finished when:

All required CORE pages are created.

Users can browse products and view their details.

Shopping cart functions work correctly.

Product quantities and total prices are calculated correctly.

The checkout form validates user information.

A confirmation message appears after placing an order.

The cart is cleared after a successful checkout.

Loading, error and empty states are included.

The application works on mobile and desktop.

There are no TypeScript or ESLint errors.

The production build works.

The README file is completed.

The project is deployed.
